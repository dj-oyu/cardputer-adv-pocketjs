# Generic rectangle geometry through existing identity skin batch
Test-only. No product code, wire, alpha mask or private character data changes.
Uses Scene.evaluateSkins with identity G/IB, one joint per visible mesh, weight65535. Hidden descriptors omitted; empty batch accepted. Geometry and normals are supplied synchronously, snapshot is checked after input poison, visibility mutation and disposal. +Y-down camera [0,0,400,0,0,0,20,120,67].
343 binary64 control combinations forward/reverse; Float32 halfheight, independent C analytic integer-lattice top-left coverage. Native raster uses integer x/y samples, not x+0.5/y+0.5 (ksn_mesh_prepared.c gouraud_edge_value). The initial pixel-center oracle failed at n=2,x=160,y=67; this test corrects that assumption based on source, not an image-derived reference. Near .98 a visible subpixel-height rectangle still covers its center integer row (40 pixels). Projection bounds are Float32 before coverage. No arbitrary-alpha, private-shader, full morph, OOM, production admission or physical20fps claim. Allocation ledger only, no warm allocation-zero claim. ASan/UBSan, LSan off.
Run python tools/blink_geometry/run.py. Native build inputs and per-arm logs retained in .cache/blink-geometry-host.
