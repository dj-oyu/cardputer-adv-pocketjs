# BIG WAVE（`apps/bigwave/big_wave.js`）

崩れていく大波の面を、サーファーの背後・少し上（TPS）から見て滑るゲーム。描画は `pocket.kasane.procedural` の線分だけ（塗りも隠面消去も無い）。メニュー行は `local.bigwave`（APPS の BIG WAVE）。設計・検証・実機で詰める項目は [docs/apps/big-wave.md](../../docs/apps/big-wave.md)。ここはソースを読む人のための要点。

## 操作

| キー | 動作 |
| --- | --- |
| `e` | 加速（波を蹴る／トリム） |
| `s` | ブレーキ（波の後ろ、カールの方へ下がる） |
| `a` / `d` | 旋回。壁は左にあるので `a` で面を登り、`d` で谷へ下る |
| `;` | ポップ（ジャンプ）。岩・他のサーファーを越える |
| `.`（押し続け） | しゃがむ。バレルと崩れるセクションは、しゃがんで低い位置でないと波頭に叩かれる |
| `,` / `/` | 急旋回（左・右）。速度を失う。波頭の近くで `,` を使うと加点 |
| `1` | 開始／再挑戦 |
| `2` `3` `4` | 描画の負荷 LIGHT / MID / HEAVY（タイトル・クリア・ゲームオーバーの画面で） |
| `tab` | 一時停止 |
| `` ` `` | 終了（Back。`frame(0x2000)` の保存ターンでは描かず、ログだけ出す） |

`f` `space` `enter` `z` は使わない（キーボード行列のゴースト。A+S+D→F、`;`+`,`+`/`→Enter など、[keystate.md](../../docs/platform/keystate.md)）。ゴーストは余分なキーが「押された」と出るだけなので、使わないキーに出る限り遊びに影響しない。

## ソースの読み方

- **定数は冒頭の `K`（物理・コース・難度）、`C`（カメラ）、`TIER`（負荷）、`PF`（波の断面）に集めた。** 手触りは実機で遊んで決めるので、数値はここだけを触る。
- **波は「世界に固定した x 方向の断面（スライス）」の列。** 1 断面が CUBIC 1 本（谷 → 面 → リップ）。断面の形はカールの量 `c` と高さ `h` で決まり、どちらもカールからの距離の区分線形関数（`curlAt` / `heightAt`）。JS は区分の境目ごとに断面をまとめて 1 回の `draw` にし、VM がその中の断面を回す（`T.cu` / `T.sh`）。
- **VM に割り算が無いので、透視の 1/d は VM が断面ごとに級数で進める**（`Y`: `y *= 1 - u + u^2 - u^3`, `u = D*y`）。JS は先頭の断面の `1/d` だけを渡す。
- **カメラのロールは VM に渡す基底ベクトル（`e`）に入っている。** 制御点は `T + l*a + v*a⊥` で、`a = y*F*e`。
- **サーファーはロール角 7 段 × 立ち／しゃがみの型付き点列（affineQ14Points）14 本。** 画面の位置は固定（カメラが追う）で、ロールの段ごとに光軸（消失点）回りに回した位置に登録してある。
- **plan は 22 本。** 起動時に 6 本、残りはタイトル画面で 1 フレーム 1 本。セット（海の区間）の切れ目で波・海・空・泡の 5 本を差し替える（1 フレーム 1 本）。走行中は登録しない（実機で 1 本 12〜20 ms）。
- プログラムは MEGADEMO と同じ文字列表記（1 文字の命令と引数、`$x` が引数）。関数を plan ごとに書くとゲストのヒープを食うので、文字列 1 つを 1 つの関数が解読する。
- 音は `pocket.audio.tone`（1 声）。鳴っている間の次の音は捨てずに短いキューで待たせる。ノイズもミキシングも無いので、波の音は低い短音で代用した。アプリの音はホームの BGM を止める（`pocket_av_background_stop("tone")`）。

## ホストで遊ばせる

```bash
# WSL。実物の QuickJS・pocket.kasane・pocket.input.keys で台本とボットを流し、全フレームを検証する
python3 tools/games/run_big_wave.py            # ASan/UBSan
python3 tools/games/run_big_wave.py --m32      # 実機と同じ 8 B JSValue（ゲストヒープの数字はこちら）
python3 tools/games/run_big_wave.py --sheet    # docs/apps/big-wave-preview.png を作り直す
```
