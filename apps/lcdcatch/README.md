# LCD CATCH（`apps/lcdcatch/lcd_catch.js`）

決まった形のセグメントを点けたり消したりするだけで遊ぶ、液晶ゲーム機の型を借りたゲーム。屋根の上で網を持った子が、4本の筋を1段ずつ落ちてくる星を受ける。設計の判断・却下案・host の実測・実機で決めることは [docs/apps/lcd-catch.md](../../docs/apps/lcd-catch.md)。ソースのコメントを短くした理由の置き場がここ（ゲストは起動時にソースを解析するので、バイト数がヒープを食う）。

## 遊び方

| キー | 働き |
| --- | --- |
| `a` / `,` | 左へ1マス（押すたびに1回。押しっぱなしで連続しない） |
| `d` / `/` | 右へ1マス |
| `1` / `2` | GAME A / GAME B を始める（タイトルとゲームオーバーの画面で） |
| `e` / `;` | 選んでいる方のゲームを始める |
| `s` / `.` | GAME A と B の選択を切り替える（タイトルで点滅している方が選択中） |
| `tab` | 一時停止・再開 |
| `` ` ``（Back） | 終了。最高得点を保存する |

星が網の真上の段（4段目）にいる間に、次の拍が来た瞬間に網がその筋にあれば1点。いなければ星は屋根の下で割れて（`X`）ミス。ミス3回でゲームオーバー。200点・500点でミスが消える。拍は得点とともに短くなる。

## コードを読むための注

- **セグメントの3種類。** (1) 固定の ref の色を `INK`（点灯）と `GH`（消灯の薄い影）で切り替えるもの: 文字ラベル5つと7セグメント21本。(2) 行ごとに1つの ref を、その行の4つの固定位置のあいだで `setRect` で動かすもの: 星4行と割れた星1つ。消灯の位置には影だけの静的なノードが下に描いてある。(3) キャッシュの instance を `place` の `opacity` で点灯（255）と影（`GO`=26）に切り替えるもの: 網の子4人とミスの印3つ。
- **(2) があるのは Kasane の上限のため。** 1つの更新で公開できる ref は32個まで（`KASANE_REF_LIMIT`、超えると `the update exposes more than 32 draw references`）で、`patch` はノードを足せない（`core_add` は REPLACE だけ）。全部を固定の ref にすると 5+21+16+4=46 個で入らない。星は1回の拍に1個しか増えず、全部が同時に1段下がるので、1つの行に星は多くても1個 — 行ごとに1つの ref で足りる。ref は31個（ラベル5・数字21・行5）。
- **`setRect` は clip を動かさない。** ノードの clip は作ったときの bounds のままなので、動かす ref には行全体の clip を最初に渡してある（渡さないと、元の位置以外では何も見えない。host の画像で一度踏んだ）。
- **描画は差分だけ。** 毎フレーム `paint()` が「どのセグメントが点くべきか」を作り、`flush()` が前回と違うものだけを1回の `patch` に入れる。変化の無いフレームは `patch` を呼ばない。`patch` が投げたら（前の提出が表示待ちの `BUSY` など）、表示中の状態を「不明」にして次のフレームで全部書き直す。
- **拍はフレームで数える。** `T.tick` などは 30 fps のフレーム数。実機のフレームが落ちると拍も遅れる（時計で測らないのは、同じ台本で同じ結果を出すためと、液晶ゲームの「カクッ」を拍の単位で保つため）。
- **音**は `pocket.audio.tone`（capability `audio.tone`、manifest では optional）。拍ごとの短いクリック、受けたとき、ミス、開始。1度に1音で、鳴っている間の次の音は `BUSY` で断られる（握りつぶしている）。音が使えない本体では黙って鳴らさない。
- **最高得点**は `pocket.storage` の `hi` に `[GAME A, GAME B]`。ゲームオーバーと Back（`frame(0x2000)`）で、更新があったときだけ書く。`storage.kv` は manifest の optional に足した（`main/pocket/app_registry.c` のこのアプリの行）。
- **乱数**は `pocket.random.create(pocket.random.seed())`。星の筋は前の星から `T.jump` 筋以内（空いた拍1つにつき1筋広がる）に限る — 1拍で届かない筋に続けて落ちると、押す速さでは取れないため。
- `globalThis.lcdCatch` は状態の入れ物で、host の試験（`tools/games/run_lcd_catch.sh`）がこれを読む。

## 調整用の定数（`T`）

| 名前 | 既定 | 意味 |
| --- | --- | --- |
| `tick` | `[13, 10]` | 0点のときの1拍のフレーム数（A, B）。13 フレーム = 約 2.3 Hz |
| `fast` | `5` | 最短の拍（約 6 Hz） |
| `step` | `20` | この点数ごとに拍を1フレーム縮める |
| `spawn` / `ramp` / `most` | `[0.45, 0.6]` / `0.004` / `[0.8, 0.9]` | 1拍で星が生まれる確率、その1点あたりの増分、上限 |
| `jump` | `[1, 2]` | 新しい星が前の星から離れてよい筋の数 |
| `missF` | `36` | ミスの後の停止（割れた星が点滅する） |
| `lampF` | `24` | 起動時の全点灯 |
| `blinkF` | `15` | タイトルの点滅の半周期 |
| `clear` | `[200, 500]` | ミスが消える点数 |
| `gain` / `click` | `0.3` / `1600` | 音量、拍のクリックの周波数（0で無音） |
