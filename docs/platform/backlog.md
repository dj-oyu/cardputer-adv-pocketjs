# プラットフォームの未解決事項

`docs/platform/` の文書から出た、現時点で本当に開いている作業だけを集める。完了・陳腐化した項目はここに置かない。

## srcstore / エディタの不具合（2026-09-15 にコードで再現を確認）

2026-09-06 の実装レビュー（基準 commit `2b053b7`）が指摘し、現在のコードでも残っている2件。

1. **`srcstore` が破損復旧後、次の保存で正常な面を消す経路が残っている。** `main/text/srcstore.c` の `newest()` は magic と長さだけで「最新」を選び、本文 CRC を見ない。最新面の本文が壊れていても `newest()` はそれを指し続け、次の `srcstore_save()` は `(current+1)%FACES`、つまり**残っている正常な面**へ書く。「新しい面はヘッダ正常・本文 CRC 不一致、古い面は正常」の状態で電源断すると、両面から復旧できなくなる。対応案: 保存先の選定も CRC 検証済みの面を基準にする。
2. **保存失敗時に「未保存」表示が解除される。** `main/ui/codeedit.c` の `do_save()` は `srcstore_save()` の戻り値を通知文字列にしか使わず、成否に関わらず `doc.changed=false; stored=true` にする。`open_slot()` も読込長 0 を「未作成」と同一視するため、空文書を保存すると次回はテンプレートで開き直る。対応案: 読込結果を正常（0 bytes を含む）／未作成／破損／I/O 失敗で区別し、保存成功時だけ未保存表示を解除する。

同じレビューの残り2件（ForceStop の検出順序、`jsconsole.c` の UTF-8 行送りでの文字欠け）は解消済み。
