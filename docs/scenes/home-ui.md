# ホームUI設計

文字主体のXMB風ホーム。アイコンは使わず、名称と設定値へ表示幅を割く。花の背景（FLOWER）は他の背景と同じ枠組みに載る1つの選択肢で、方式・メモリ・検証範囲は[FLOWER背景](flower.md)を参照。XMB の設計経緯は[archive/findings.md](../archive/findings.md)。

## 操作と情報構造

XMBの横カテゴリ・縦リストを文字で表現する。
方向入力は論理的なLeft/Right/Up/Downへ変換し、Enterで決定、Esc相当のキーで戻る。
ホームは矢印刻印キー単独とFn＋矢印、Enter、左上キー単独またはFn＋同キーのEscを扱う。編集欄では文字入力と衝突しないFn付き操作を使う。
日本語入力中のEscはIMEが先に取消として処理する。通常のBackとは別にForceStop操作を設ける（[入力設計](../apps/japanese-input.md)）。

左右でApps / Settings、上下で選択カテゴリの項目を移動する。現在のApps行は `main/ui/shell.c` の `apps[]` テーブル1つが真実で、この文書には列挙しない（行を足しても既存の起動順は変わらない設計。テーブル末尾へ追記する規約は同ファイルのコメントを見ること）。Settingsは BACKGROUND / FPS DISPLAY / SOUND / VOLUME（[XMB設定と操作音](xmb-settings-sound.md)）。未実装カテゴリは並べない。
カテゴリごとの選択項目を保持し、アプリから戻ると同じ位置を選択する。
初期仕様では端で停止し、循環しない。Enterの長押しで多重起動しない。

## 240×135の配置

| 領域 | 座標の目安 | 内容 |
| --- | --- | --- |
| カテゴリ | 選択文字開始(16,37) | 文字列を96px間隔で横移動 |
| 選択項目 | 文字開始(16,69) | 2倍ASCIIフォント。明暗で選択表示 |
| 値・説明 | (16,89) | 選択項目の直下 |
| 前後の項目 | y=12 / 110付近 | 縦列が移動。カテゴリ行を横切る間は減光 |
| FPS | (194,8) | 設定で有効時のみ。常設の操作案内や機種タイトルは置かない |

選択項目を最大コントラストにし、周辺項目を暗くする。文字サイズを過度に縮小しない。
現在の同梱項目名は表示幅に収まる。任意の長い名称の省略・横スクロールは今後の設計対象。
カテゴリー切り替え時は縦リストも追従し、見た目の座標と選択状態を分けて管理する。

## 背景

BACKGROUND設定は3択（LEVEL WAVE / OCEAN + STARS / SOLAR SAIL、`main/ui/shell.c` の `SCENES[]`）。いずれもその場で計算して描画し、動画や全画面の大きな画像列は使わない。半透明に見える配色はstrip内で計算し、巨大な透過レイヤーを常駐させない。ネイティブShellで描画し、JSアプリと同時には動かさない。

波と海面はPIEカーネルで背景行をベクトル化している（[pie-simd.md](../perf/pie-simd.md) §7に実測）。SOLAR SAILの詳細は[SOLAR SAIL](solar-sail.md)、FLOWERの詳細は[FLOWER背景](flower.md)。

ui_taskのフレーム目標は約30Hz。背景が動くと画面の広い範囲が毎回更新されるため、damage描画だけで転送が小さくなるとは仮定しない。描画とSPI転送の合計時間を測り、負荷が高ければ背景の更新頻度・波の本数を下げる。

## 遷移と応答

現在は時定数45msの指数補間で目標位置へ追従する。120〜180msは初期設計値で、固定の遷移所要時間ではない。
入力1回ごとにアニメーション完了を待たない。時間はフレーム数ではなく単調時刻から求める。
設定はEnterで子階層を開き、上下で候補を選び、Enterで保存して戻る。Escは保存せず戻る。親を左へ移動させる。起動時の暗転演出は未実装で、アプリへ直接切り替える。
アプリ終了後は転送とメモリの解放を完了してからホームの描画を再開する。

## エラー画面

エラー種別、短い説明、戻る操作をネイティブ描画する。長いstack traceは将来のConsoleへ回す。
例外・メモリ不足からの通常復帰と、watchdog再起動を区別する。
停止確認が取れないときにホームへ遷移したように見せて、古いアプリを裏で走らせない。
