# ホーム背景の比較（2026-09-06）

## 現行版: 粒子の常時表示と波筋による海面

ユーザーの実機評価で、従来のノイズ陰影が波に見えなかったため海面を変更。
現行版の左右切替は `WAVE + STARS` / `OCEAN + STARS` の2種類。
どちらも粒子36個を常時表示する。

海面は水平線（y=36）と遠近法による波間の圧縮、手前へ流れる波筋、
交差する細波、波頭に沿って途切れる反射を組み合わせる。
Perlin noiseは面の色ではなく波筋の湾曲に使用する。
正弦波を256要素の表にし、画素ごとの三角関数計算を避ける。

実機の安定後測定: 波＋粒子30.3 FPS（描画約32 ms）、海面＋粒子25.0 FPS（約39.3 ms）。
本体915,344 bytes。辞書・日本語フォント各2 MiBの予約を維持。
ベンチマークも現行2種類に更新済み。

## 初回比較の記録（以下は旧4種類版）

実機書き込み済み。ホームの左右キーで4種類を切り替える。選択は再起動まで維持。
右上にFPS、左上に背景名を表示。カテゴリ選択が必要になる前の背景比較用操作。
USBからは `a` / `b` でも切り替えられる。

| 背景 | 初版FPS | 最終FPS | 最終平均描画時間 |
| --- | ---: | ---: | ---: |
| WAVE: 元の波 | 21.8 | 28.6–29.6 | 33.2–34.2 ms |
| OCEAN: 海面 | 11.8 | 21.3 | 46.6 ms |
| STARS: 波＋粒子36個 | 18.2 | 28.6 | 34.4 ms |
| SEA + STARS: 海面＋粒子36個 | 10.5 | 20.6–20.7 | 47.8–48.0 ms |

各モードを約8秒観測。切替直後のサンプルは初期化時間の影響を含むため、
海面と粒子の表は安定後の値。FPSは液晶への転送完了まで含む実表示更新回数、
描画時間は背景計算・文字描画・SPI転送を含み、フレーム待機時間を含まない。
約30 FPSを目標に残り時間だけ待機し、負荷が超える場合も最低1 tick待機する。
画像転送中は測定対象外。見た目の最終評価は実機で行う。

## 実装と調整

海面は8方向勾配とquintic補間による2D Perlin noiseを2オクターブ合成し、
高さと勾配から青緑の陰影を作る。流体シミュレーションではなく海面風の表現。
41×24の格子でノイズを計算し、240×135へ整数補間する。
粒子は36個を位置・速度・明滅の異なる点として描き、一部に十字の光を付ける。
アニメーションは実時間に基づくため、FPSが変わっても移動速度は変わらない。

1. 初版: 各画素で浮動小数点補間。粒子はstripごとに再計算。
2. 整数補間、粒子計算を1フレーム1回に集約。海面＋粒子が約18 FPSへ改善。
3. strip外の文字・粒子を早期に除外。波＋粒子が約29 FPS、海面＋粒子が約21 FPSへ改善。

ノイズ格子1,968 bytesと粒子配列432 bytesを静的確保し、フレームごとのheap確保はない。
全画面バッファは追加せず、240×8画素単位の転送を維持。
ファームウェア915,296 bytes。M1比+2,896 bytes。
SKK辞書2 MiB・日本語フォント2 MiBの予約領域を維持。

## 再測定

書き込み／再起動直後（WAVE状態）にIDF環境で実行する。

```powershell
python tools/benchmark_background.py --port COM3
```

生ログは `.cache/backgrounds/performance.txt` に保存する。
滑らかさ重視ならWAVE/STARS、海面の表情を優先する場合はOCEAN/SEA + STARSを選ぶ。
起動時は元のWAVEを維持する。
