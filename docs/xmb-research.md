# PSP XMBの再調査とホーム設計の修正方針

調査日: 2026-09-06。文字主体の初版を実装・実機書き込み済み。検証結果は末尾。

本書の「現行」「現在」と測定値は文字主体初版 `54f5304` の記録。後続の日本語入力・Playground追加、フォント512KiBへの変更は[現行仕様](architecture.md)と[ホーム仕様](home-ui.md)を参照する。

## 誤っていた点

現行の `main/shell.c` は、固定位置のAPPS/SETTINGSと下線、その下の固定行一覧で構成される。カテゴリ変更は文字色と下線位置、項目変更は `>` の位置を変える。左右・上下のキー割り当てだけがXMBと一致している。

XMBとして必要な、同一空間に交差するアイコン列、選択位置へ列を運ぶ動き、階層を位置関係で示す表現を欠いていた。背景だけを動かしてもこの構造の差は解消しない。

## PSPの公式画面から確認できること

[PSP-3000 日本語クイックリファレンス](https://www.playstation.com/content/dam/global_pdc/en/corporate/support/manuals/psp-docs/JA_PSP-3000-4.2_2_WEB.pdf) の印刷ページ2–3を画像化して確認した。

- 横にカテゴリ、選択カテゴリと同じ横位置に縦の項目列がある。方向キー左右／上下でそれぞれ選択する。
- 設定の例では、カテゴリの上にUSB接続、下に選択中のビデオ設定と後続項目が見える。縦列を下半分だけに閉じ込める構成ではない。
- 選択カテゴリと選択項目は別の位置。項目名は項目アイコンの右にあり、非選択項目は淡い。共有する背景に仕切りはない。
- 右上は日時・電池。オプションは△で開く別状態で、再生中の操作パネルとも区別される。

ソフトウェアの版でアイコンは変わる。ここで見た画面を全バージョンの完全な仕様とは扱わない。

## 動きの設計を裏付ける資料

[Sony Computer Entertainmentの公開出願 US20110010667 A1](https://uspto.report/patent/app/20110010667) の実施例、段落0050–0054を参照した（出願本文の転載）。

横列のスクロールに伴う縦列の収納／展開、縦列全体のスクロール、注目位置での拡大、アイコン右の説明、子階層へ進む際に親と横列を左へ移す仕組みが記載されている。交点と、その直下の項目注目位置を分けている点が重要。

これは設計思想の一次資料であり、PSP製品の全挙動を保証する資料ではない。実機動画のフレーム計測は未実施。アニメーション時間、補間曲線、端での循環や全カテゴリの選択保持規則は断定しない。

## Cardputer向けの提案

以下は本プロジェクトの設計判断。PSPの座標・速度を測定した値ではない。

ユーザー指定: アイコンは使わず、240×135の表示面積を文字に割り当てる。PSPのアイコン表現は再現せず、横・縦の関係と列が選択位置へ移動する仕組みを文字で表現する。

1. 横のカテゴリ名の列と縦のリソース名の列を、背景上の同じ座標系で扱う。固定タブ、下線、一覧用パネルを撤去する。アイコン用の余白は確保しない。
2. ホームでは選択カテゴリの横位置を固定する。左右入力で横列がそこへ移り、そのカテゴリの縦列を展開する。カテゴリを決定してから上下操作へ移る追加段階は設けない。
3. 項目にも定位置を設け、上下入力で文字列を移す。選択項目は明るい文字、前後は淡い文字にする。名称を優先し、設定値や短い説明は選択項目の直下に表示する。前の項目はカテゴリ列より上にも見せる。選択枠やカーソル記号に表示幅を使わない。
4. カテゴリの交点と項目の注目位置には間隔を置く。移動中の項目とカテゴリが重ならないよう、カテゴリ帯をまたぐ間隔・透明度を補間する。
5. 設定はBackground、FPS display、Soundの縦列。決定で選択肢の子階層を開き、親を左へ退かせる。戻ると元の項目へ復帰する。Hello Worldは決定で起動する葉として扱う。
6. 波・海面・パーティクルは継続する。文字の周囲は暗く保ち、選択の強調を背景より優先する。傾きは背景に適用し、操作の基準位置は安定させる。

### 配置の出発点（240×135）

| 要素 | 仮の位置 |
| --- | --- |
| 選択カテゴリの文字開始位置 | (16, 37) |
| 隣接カテゴリの間隔 | 実際の文字幅＋24px。画面外はクリップ |
| 選択項目の文字開始位置 | (16, 69) |
| 名称に使える幅 | 208px（左右16pxの余白） |
| 選択項目の値・説明 | (16, 89)付近 |
| 直前の項目 | (16, 12)付近、淡く表示 |
| 次の項目 | (16, 110)付近、淡く表示 |

前後の項目間隔はカテゴリ列との衝突回避のため一様にしない。カテゴリ2個でも横列を移動させ、空のカテゴリは追加しない。選択カテゴリと項目の文字開始位置を揃え、所属関係を示す。常設の操作案内で最下段を占有せず、必要な場面に絞る。長い名称は読みやすい文字サイズを維持して省略し、選択が落ち着いた後の横スクロールを検討する。

### 実装時に分離する状態

- 論理状態: categoryId、カテゴリごとのitemId、階層の履歴。
- 表示状態: 横列の位置、縦列の移動量、展開率、親階層の退避量、選択の強調率。
- アプリ状態: 起動、実行、停止、エラー。ホームのナビゲーションから独立させる。

補間は経過時間で計算し、連打中も新しい目標へ追従する。既存の120–180ms案は調整用の初期値であり、PSPの測定結果ではない。各stripで時刻を取り直さず、1フレームで同じ表示状態を使う。

### 次の実装での確認基準

- 左右を押したとき、カテゴリ名の色だけでなく文字列の位置が変わる。
- アイコンやその予約領域がなく、名称が表示幅を使える。
- 上下を押したとき、選択位置を保って前後の項目が入れ替わる。
- 直前の項目がカテゴリ列の上に現れ、上下に分割されたパネルに見えない。
- 子階層への移動と戻りで、親子の位置関係を追える。
- 設定保持・Hello Worldへの往復・効果音のオン／オフが維持される。
- 静止時に加え、連打・階層移動・効果音を重ねた状態のFPSと最大フレーム時間を測る。

この資料を、旧home-ui.mdの画面配置案に優先する。既存のxmb-settings-sound.mdは前回実装の記録として残す。

## 文字主体の初版・実装結果

- カテゴリ名の横スクロール、項目名の縦スクロール、選択肢への水平遷移を実装した。文字幅は現在の2カテゴリに合わせ96px間隔。可変長カテゴリへの対応は今後の拡張時に行う。
- 項目は2倍のASCIIフォント。選択は明暗で示し、値・説明を直下へ配置した。文字がカテゴリ行を横切る間は減光する。アイコン、下線、カーソル記号、常設操作案内を撤去した。
- 設定はEnterで選択肢を開き、上下で選び、Enterで保存して戻る。Escは保存せず戻る。カテゴリ・設定項目の選択はアプリ往復でも保持する。
- 設定変更・キャンセル・消音と再有効化・Hello Worldへの往復をUSB操作で検証。10回のアプリ往復で空きheap 324428 bytes、最大連続領域204800 bytesを維持し、6種のエラー後の復帰も成功した。
- 静止メニュー: LEVEL WAVE約25–26fps、OCEAN約28–29fps。約80ms間隔の連続操作と効果音を重ねた測定: LEVEL WAVE約23–25fps、OCEAN約25–27fps、最大描画時間は54.22ms。取得画面の転送時間はこの計測から除外した。
- 最終バイナリ973488 bytes。3MiBのアプリ領域に2172240 bytesの余裕があり、SKK辞書2MiB・日本語フォント2MiBを維持した。
- `tools/capture_home.py`で実機のLCD描画データから3画面を取得して配置を確認。診断画像の欠けを防ぐため、取得時だけ各行送信後に5ms待つ。通常表示への待ち時間追加はない。

画面の見え方・移動の感触・実際の音質についてはユーザーの実機評価を受けて調整する。現状は英字表示で、日本語フォントとSKKの実装とは独立している。
