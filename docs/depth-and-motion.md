# 被写界深度・奥行き・傾き連動（2026-09-06）

元の波背景を `DEPTH / TILT` に更新。海面との左右切替と常時パーティクル表示を維持。

| 層 | 波の表現 | 傾きによる最大移動量の目安 |
| --- | --- | ---: |
| 奥 | 暗く、幅広くぼかした青い波 | 約3 px |
| 中 | 焦点が合った細く明るい波 | 約8 px |
| 手前 | 幅広いぼけと大きなうねり | 約20 px |

粒子36個も3層に分ける。遠景は暗い点、中景は鋭い点、前景は5×5範囲の柔らかな光。
これはレイヤーごとのぼけ幅で被写界深度を近似する表現。全画面ブラーや深度バッファは使わない。
波形は正弦波テーブルを使い、ぼけの強さも初期化時にテーブル化する。
文字とメニューは固定。傾きによる視差は波背景のみに適用し、海面の表現は維持。

## 傾き入力

[M5Stack公式仕様](https://docs.m5stack.com/en/core/Cardputer-Adv)のBMI270を使用。
[Bosch公式SensorAPI](https://github.com/boschsensortec/BMI270_SensorAPI)を
`41129fcfe39c583ee5462d79195741945d51c1fe`に固定。
ライセンスは `licenses/BMI270.txt` に同梱。

GPIO8/9の既存I2Cバスを共有し、0x68/0x69をプローブして公式初期化処理を実行。
加速度のみ50 Hz・±2g。ジャイロは有効化しない。
キーボードとIMUの通常読み取りは同じ入力タスクで直列実行し、UIはatomic値を読む。
最初の有効サンプルを基準姿勢とし、係数0.10の低域フィルタと±約0.70gの上限を設ける。
USBの `c` で現在の姿勢を基準にし直せる。実機だけなら持ち方を決めて再起動する。
センサー未検出・初期化失敗時も静的視差で描画を続け、連続読み取り失敗時は視差をゼロに戻す。

## 実測

- 3層＋ぼけ粒子＋IMU: 安定後26.4–26.5 FPS、描画37.0–37.3 ms。
- 海面＋粒子＋IMU: 安定後29.3 FPS、描画約33.6 ms。
- 初版の3層は約20 FPS。背景だけ`-O2`にし、波形をテーブル参照へ変更して改善。
- 実機加速度ログ例: `ACC -37 -366 16784 TILT 0 0`。静置状態で約1gの読み取りを確認。
- 起動・加算・復帰10回と6種のエラー回復が成功。終了後RAMは336,276 bytesで一定。
- ファームウェア931,072 bytes。SKK辞書2 MiB・日本語フォント2 MiBの予約領域を維持。

物理的に傾けた際の向き・強さ・見た目はユーザーの実機評価を受けて調整する。
